Scan schedules

Schedule individual lists in UTC. The app must be running at the scheduled time; missed runs are skipped. Monthly schedules run only in months containing the selected day.

Normal scans respect the cache and the creator's configured per-user and server-wide daily API budgets. Force refresh bypasses both budgets and the cache and can spend API credits. Calls are still counted against the creator.

Overlapping scans wait their turn. Runs are skipped if the creator is no longer an active administrator. Disabling or deleting a schedule cancels queued runs, but does not stop a scan already in progress.
